## About Me

I currently work in reverse engineering. My main interests are operating systems, hypervisors, compiler optimization, program analysis, and other low-level software and related security mechanisms.

- `ccOS`: A UEFI-booted x64 operating system kernel I once attempted to write; I am no longer actively developing it.

- `cc-pass-python`: Demos I wrote while studying compiler IR optimization, implementing algorithms such as control flow analysis, SSA, data flow analysis, constant propagation, and symbolic execution.

- `ReflectiveDLL`: A reflective DLL project based on `oldboy21/RflDllOb`, used as a central component of a C2.

- `c2-suite`: A post-exploitation framework implemented in Golang and C++, with parts of its code design derived from reverse engineering and written by AI.

I welcome discussions on low-level technology, security offense and defense, compiler principles, and any other interesting topics.
